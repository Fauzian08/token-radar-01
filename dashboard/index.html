    How to read this page

    The board ranks pre-token protocols by implied value: what a token would be worth, times the chance one ever appears. It is a model of the snapshot's own record, not a forecast and not a promise: the page never says a token will launch. Values are fitted, not set by hand; every coefficient is printed with the tests it survived, and the ranges are bootstrap ranges, not guarantees.
